ABOUT THE PROJECT

In a world of headlines, context matters.

Verity is a Web Technology project exploring how simple computational methods can help readers reflect on the language used in news articles.

01 / PURPOSE

Encourage critical reading.

The project examines selected sensational wording, punctuation, and uppercase expressions that may influence how a headline is perceived.

02 / TECHNOLOGY

A practical web application.

Flask handles application routes, Python performs the initial language-pattern analysis, SQLite stores reports, and HTML, CSS, and JavaScript power the interface.

03 / LIMITATIONS

Signals are not verdicts.

This prototype does not independently verify claims, identify trustworthy sources, or determine whether an article is true. Its initial scoring system is rule-based, not a trained machine-learning model.

THE NEXT STEP

From language signals to evidence-based analysis.

Future improvements could include a trained text classifier, source verification tools, and more extensive evaluation against labeled data. Such additions would need careful testing before making credibility claims.
